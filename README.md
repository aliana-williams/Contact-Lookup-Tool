# Contact Lookup Tool

## Overview
This Python program allows users to search for phone numbers using email addresses stored in a dictionary. The application demonstrated data retrieval and user input handling.

## Features
- Stores contact information using dictionaries
- Searches for phone numbers by email address
- Displays matching phone numbers
- Handles invalid or missing entries

## Technologies Used
- Python

## How It Works
1. The program stores contact information in a dictionary.
2. Users enter an email address.
3. The program searches for the email in the contact list.
4. If found, the associated phone number is displayed.
5. If not found, an error message appears.
6. Users can continue searching until exiting the program.

## What I Learned
This project helped me practice working with dictionaries, creating lookup functionality, and handling user input.
